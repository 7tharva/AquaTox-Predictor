About This Project

A full machine learning pipeline for aquatic toxicity prediction — built for ENGG2112.

Overview
What is AquaTox Predictor?

🎯 Project Goal

  • Predict LC50/EC50 aquatic toxicity without animal testing
  • Binary classification — Acute 1 (LC50 ≤ 1 mg/L) vs non-toxic
  • Regression — predict exact log(LC50) concentration
  • SHAP explainability for every model's predictions
  • Grouped cross-validation to prevent chemical data leakage
  • 13 models tuned end-to-end with GridSearchCV

Architecture
Pipeline steps
Every step designed to maximise scientific rigour and prevent leakage.
  • 1

    Data Loading & Filtering

    CSV loaded with smart column selection — only columns needed are read into memory. Filtered by tax group (fish), endpoint (LC50), and effect (MOR). Chemical DTX IDs used as group identifiers.

  • 2

    Feature Engineering

    Numeric features (experimental + chemical), one-hot categorical encoding, and bit-expanded molecular fingerprints (PubChem, MACCS, Morgan, ToxPrint — top 128 most variable bits each). Mordred descriptors and Mol2Vec embeddings included where present. Leakage check built in.

  • 3

    Grouped Train / Test Split

    StratifiedGroupKFold with 5 splits. Class balance preserved. No chemical appears in both train and test folds — prevents inflated metrics from structural analogues.

  • 4

    Model Tuning with GridSearchCV

    7 classifiers and 6 regressors each wrapped in a sklearn Pipeline: Imputer → VarianceThreshold → SelectKBest (up to 150 features) → optional StandardScaler → model. Tuned with 3-fold grouped CV.

  • 5

    SHAP Explainability

    TreeExplainer for XGBoost, LightGBM, Random Forest. KernelExplainer for LR, NB, KNN, MLP. Summary bar, beeswarm, and cross-model comparison plots for all 13 models.

  • 6

    Prediction & Deployment

    Models saved with joblib and loaded into this Flask app at startup. New compounds evaluated in real time using the full trained pipeline.

Caveats
Limitations & notes

⚠️ Important caveats

  • Predictions trained on t-F2F (fish mortality) only — crustacean and algae challenges require separate models
  • Molecular fingerprints and Mordred descriptors not computed from SMILES in this interface — structural features default to zero, reducing prediction quality
  • KernelExplainer SHAP values capped at 300 samples for runtime — approximate for kernel-based models
  • Grouped CV prevents same-chemical leakage but dataset may still contain structural analogues across groups
  • Log-transformation applied to LC50 before regression — predictions back-transformed with expm1
